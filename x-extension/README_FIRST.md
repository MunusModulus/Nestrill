# Nestrill X Extension v1.0.0

Helium用の追加拡張機能です。NestrillとX（旧Twitter）を共通サイドバーから切り替えられます。Nestrill本体は同梱していません。

## 必要な環境

- Windows 11 x64、Helium（左側にサイドパネルを表示する設定を推奨）
- [Nestrill v0.2.3](https://github.com/MunusModulus/Nestrill/releases/tag/v0.2.3) を導入し、PC上で起動していること（http://127.0.0.1:8767/）
- Xを閲覧するためのインターネット接続と、必要に応じてXへの通常のログイン

他のブラウザ・Heliumの全バージョンでの動作は保証しません。Heliumの分割表示との併用は非対応です。

## 導入（Chromeウェブストアを経由しない方式）

1. ZIPを永続ディスク上の専用フォルダへ展開します（例：`%LOCALAPPDATA%\Nestrill-X-Extension`）。展開先の直下に `manifest.json` があることを確認します。RAMディスクや一時フォルダは使用しないでください。
2. Heliumで `chrome://extensions` を開き、「デベロッパーモード」をONにします。以前のProof09／X Editionが入っている場合はOFFにします（動作確認が済むまで削除しないでください）。
3. 「パッケージ化されていない拡張機能を読み込む」を押して、手順1のフォルダを選択します。Nestrill X ExtensionだけをONにします。
4. Nestrillを起動し、通常のPC用URLをHeliumで開きます。既に開いている場合は `Ctrl+F5` で更新します。
5. 左ペインの「X（共通ペインを開く）」を押します。ブラウザの共通サイドパネルが開いたら、「左ペインを共通表示にする」を押します。
6. 共通ペインの「X（Twitter）」でXに切り替えます。「すべての記事」などのNestrill側の項目で戻れます。

## 操作と制限

- 初回のX表示後、Xのページを背面に保持して、その上にNestrillを表示します。通常切替ではXを再読込しないため閲覧位置を維持しやすくなります。ただしXの自動更新やブラウザによるタブ破棄等で位置が変わることがあります。
- RSS表示中のXの横にある「終了」は、背面のXを終了して次回新しく読み込む操作です。確認ダイアログが出ます。Xの閲覧位置は失われます。
- 共通ペインの歯車、RSS登録、プロファイル切替・管理は、Nestrill本体の画面を利用します。本体の設定やデータは通常どおり保存されます。
- 共通ペインは通常のNestrillの表示設定に追従します。動画・アニメーション背景の左右完全同期、完全な背景透明化には対応していません。
- 拡張機能が有効なNestrillページではシークレットモードは非対応です。利用する場合は拡張を無効にして通常のNestrillページを更新してください。
- NestrillとXは独立したサービスです。本拡張機能はXおよびHeliumの公式製品ではありません。Xの利用条件に従ってください。

## 権限とデータ

- `tabs`：連携対象のタブを特定し、URLと表示状態を確認・切替するため。ブラウザが閲覧履歴等へのアクセス警告を表示する場合があります。
- `storage`：連携中のメニュー、閲覧位置、タブの状態等をブラウザのセッションストレージに保持するため。
- `sidePanel`：共通サイドバーを表示するため。
- `http://127.0.0.1/*` と `http://localhost/*`：Nestrill本体との連携。Chromeのマッチパターンはポートを限定できないため、スクリプト側で8767番ポートを確認しています。
- X／Twitterの指定HTTPSドメイン：Nestrillの重ね表示を設置・切り替えるため。Xの投稿本文・認証情報を取得する処理や外部のテレメトリー送信先は設けていません。X自身とNestrill本体の通常のネット通信は発生します。
- `debugger` 権限は要求しません。

## 更新・無効化・削除

更新する場合は、先にRSS画面で背面のXを終了し、「標準の左ペインに戻す」を押します。旧拡張をOFFにして、新版を別の永続フォルダに展開・読み込みます。旧版と新版を同時にONにしないでください。新版の動作を確認した後、必要に応じて旧版を削除できます。

無効化・削除する場合も、先にRSSへ戻って背面のXを終了し、標準の左ペインに戻します。`chrome://extensions` で無効化または削除し、Nestrillページを `Ctrl+F5` で更新します。途中で表示が崩れた場合は、拡張をOFFにしてPC用URLを開き直してください。本体のアンインストールは不要です。

## トラブル対処

- X項目が出ない：本体が起動しているか、拡張がONか、PC用URLを開いているかを確認し、更新します。
- 共通ペインが開かない：Heliumの分割表示を解除し、もう一度X項目を押します。
- RSSに戻れない／標準ペインが見えない：拡張をOFFにしてPC用URLを開き直します。旧版に戻す場合は新版OFF→旧版ON→ページ更新の順です。
- Xの仕様変更やブラウザ側の制限により、動作が変わる場合があります。
