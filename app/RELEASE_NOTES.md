# Nestrill v0.2.3 — Standard版リリースノート

2026年11月24日 / Windows 11 x64

## v0.2.2からの主な変更

- **AIセレクトの探索条件**：従来の70/20/10に加え、関心リスト・評価済み記事（「興味あり」）の利用ON/OFF、8大分類・41小分類のジャンル指定、ランダム探索に対応。
- **探索候補の多様化**：ジャンル／関心／評価履歴からのテーマ展開と重複抑制を調整。記事件数を不適切に水増ししない。
- **表示の改善**：新着順・ランダム表示、画像とリード文の補完、ジャンルアイコンと色・サイズ設定。
- **設定画面の整理**：右ペイン、左ペイン、共通背景、スマホ表示を視覚的なセクションに整理。保存・キャンセル・画面遷移の機能は維持。
- **Standard版のシークレット入口を廃止**：既存のデータは削除しない。
- **更新の安全性**：既知の旧版・RC07・RC08からの上書き更新に対応する許可リストを更新。未知の変更済みファイルは引き続き拒否。

## 変更しない点

- AIセレクトの70/20/10推薦方針、本番ポート `127.0.0.1:8767`、既存のユーザーデータと設定を保持する更新設計。
- 既存のAIモデル設定がある場合は変更しない。初回既定モデルは `gemma4:e4b-it-qat`。
- X Editionは別配布であり、このStandard本体のZIPに混在しない。

## 導入時の注意

- Windows 11 x64 / Node.js 22.16以上。AI利用には別途Ollamaと対応モデルが必要です。
- 更新前にアンインストールしないでください。アンインストールは対象インストール先の保存データも削除します。
- RC08の上書きとUIはWindows実機でPASS済み。正式版v0.2.3の新規導入とRC08からの更新は公開前の実機検査が必要です。
