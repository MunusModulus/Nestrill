# Nestrill v0.2.1 — 操作画面の整理

**公開日：2026-11-16**  
**ライセンス：MIT（© 2026 Munus Modulus）**

## 今回の変更

- AIセレクトの記事で、文章の感想を書き込む吹き出しボタンを一時的に非表示にしました。
- 「設定 → AIセレクト → 評価履歴」の編集画面でも、感想の文章入力欄を非表示にしました。
- 操作説明の「興味・感想・出典」を「興味評価・出典」に合わせました。
- 「設定 → 記事表示」の非表示ルールをRSS・AIセレクト共通として明示し、Googleニュース経由の記事は掲載元ドメインで判定するように修正しました。
- 「記事表示」の非表示ルールは1つの語句欄に **`"A"+"B"`（両方含む／AND）**、**`"A"or"B"`（どちらか含む／OR）** を入力可能にしました。演算子なしの従来の1語ルール、および旧RC08の2語ANDルールも保持します。Googleニュース経由でも記事タイトル文字列から判定します。
- 「記事表示」の非表示ルールで `example.com/sub1/` や `https://example.com/sub1/` のディレクトリ指定にも対応しました。元記事URLのパスが確認できる記事だけに適用します。

**維持されるもの**：👍興味あり／👎興味なし、評価履歴、記入済みの感想、RSS・YouTube登録、記事データ、AIセレクトの探索・推薦処理。
既存の感想データは削除せず、評価を変更する際も保持します。新たな感想入力だけを画面から隠した変更です。

## v0.2.0からの更新

- **先にアンインストールせず**、v0.2.1のセットアップEXEを実行し、従来と同じインストール先を選んでください。
- v0.2.0に今回の「感想入力非表示パッチ」を手動適用済みでも、そのパッチとインストール記録が完全一致する場合に限り更新できます。
- それ以外の変更済み・管理外ファイルは引き続き保護し、更新を中断します。データやフォルダを無理に削除しないでください。
- 新しい配布版に更新しても、保存済みのRSS、設定、履歴、評価データは維持されます。

## 利用条件と注意事項

- Windows 11 x64を主な動作確認環境とし、Node.js 22.16以上が別途必要です。AIセレクトの利用にはOllamaとAIモデルも必要です。
- Windowsサインイン後の自動起動は、ON/OFF設定を除いて未検証です。
- 署名のないセットアップEXEです。配布元を確認してから実行してください。
- **アンインストール時は利用データが削除されます。** 必要な場合は事前にバックアップしてください。
- スマホ接続やTailscaleについては `MOBILE_SETUP.md` を参照してください。

詳しい使い方は `README.md` と `SETUP_WINDOWS.md` を参照してください。
