# Nestrill v0.2.2 — リリースノート

公開日：2026-11-19

## v0.2.1からの変更

- **AIセレクトの再登場抑制**：同じプロファイルで明示的に評価した記事を、URL・タイトルの一致と必要時のみの限定的な意味判定で再推薦しにくくしました。評価履歴は関心推定の素材として保持します。
- **表示設定の改善（DisplayPrefs03）**：記事リード文、左ペイン件数表示、背景保存先の説明、AIセレクトの表記を整理しました。
- **安全な上書き更新**：v0.2.1公開版と、確認済みの表示設定・E2手動パッチの組み合わせをSHA-256で識別して更新できるようにしました。未知の変更や中途半端な適用状態は保護のため停止します。
- **更新時の復旧保護**：配布ファイルを事前照合し、書き込み前に元ファイルを一時保存。配布ファイルのコピーで失敗した際は元のファイルとインストール記録を復元する処理を追加しました。
- RSS登録、YouTube登録、評価履歴、個人設定などの利用データは、上書き更新では削除・初期化しません。

## Standard版とX Edition

本リリースは共通のNestrill本体です。X Edition固有の機能（Helium用拡張 Proof09 R9G）は別配布であり、Standard版に同梱しません。同一Nestrillサーバーを利用する場合、本体の改善はどちらの表示にも反映されます。

## 確認状況

- Windows 11 x64：v0.2.1（DisplayPrefs03／E2パッチ適用済み）からv0.2.2 RC01への上書き更新、配布ファイル68件のSHA-256照合、インストール後の起動、RSS・設定・評価履歴保持を実機確認しました。
- X Edition Proof09 R9Gとの連携、および背面X終了操作を実機確認しました。
- 本正式版では、RC01の機能コードを変えず、公開用表記・説明文・配布メタデータを整えました。正式版ビルドのWindows実機での再インストールは未実施です。
- Windowsの全環境、全ネットワーク構成、アンインストールと更新の全異常系については動作を保証しません。
- Windowsの「インストールされているアプリ」からのアンインストールでは、**利用データも削除**されます。更新時に先にアンインストールしないでください。
- デジタル署名なしのEXEです。公式GitHubの公開ファイルとリリース掲載のSHA-256を照合してください。
