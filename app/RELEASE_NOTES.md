# Nestrill v0.2.4

## 主な変更

- AIセレクトの探索実行ボタンを白背景・細い二重ボーダーに変更（現行サイズを維持）。
- 左ペインのアイコンと文字、RSS・YouTubeの展開三角、条件指定チェックボックスの整列を改善。
- スマホ版に「条件を指定して探す」を追加。新着順・ランダム、関心リスト・「興味あり」の使用有無、ジャンル指定に対応。PC版の既存探索エンジンを利用します。
- スマホ版の記事タイトルを10～19pxで設定可能にし、プルダウン矢印を統一。
- 外出先スマホ接続の一括ON／OFF用CMD、任意のデスクトップショートカット作成CMD、スタートメニューのスマホ接続ガイドを追加。既存の個別操作も維持。

## 更新・動作確認

先にアンインストールせず、利用データをバックアップして同じインストール先へ上書き更新してください。スマホ接続中は先に停止してください。
Windows 11 x64のRC03で上書き更新、起動、既存データ保持、主要なPC・スマホ機能を実機確認済みです。正式版はRC03から動作コードを維持し、バージョン・更新許可・配布文書を更新しています。正式版の新規インストールは実機未検証です。
