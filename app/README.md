# Nestrill

Windows向けのローカルRSS・YouTube新着リーダー。RSSフィードを購読し、任意でローカルAIによる記事探索「AIセレクト」を利用できます。

**バージョン:** v0.2.1  
**対応環境:** Windows 11 x64（主な実機検証環境）  
**必要なもの:** Node.js 22.16以上、Webブラウザ、RSS取得用のインターネット接続

## インストールして使う（推奨）

1. 配布ファイル `Nestrill-Setup-v0.2.1.exe` をダウンロードして実行します。
2. インストール先を確認し、「インストール」をクリックします。標準の導入先は `%LOCALAPPDATA%\Programs\Nestrill` です。管理者権限は不要です。
3. **スタート → すべてのアプリ → N → Nestrill** で起動します。ブラウザが自動で開きます。
4. 終了時は、同じN欄の **「Nestrill を終了」** を選びます。ブラウザを閉じただけではサーバーは終了しません。

Node.jsが未導入なら、先に公式サイトから導入してください： https://nodejs.org/en/download/

PC上のNestrillが起動している間は、`http://127.0.0.1:8767/` をブックマークしてブラウザから開けます。初期状態ではWindowsサインイン時の自動起動は**OFF**で、**設定 → 一般**からON/OFFできます。自動起動時はブラウザを自動では開きません。

Windowsの「設定 → アプリ → インストールされているアプリ → Nestrill」でアンインストールできます。**アンインストールすると、このインストール先のRSS登録・設定・履歴・ログなどの保存データも削除されます。** 利用データが必要なら、削除前にバックアップしてください。実行中の場合は、対象インストールのサーバーを正常停止してから削除します。

## ポータブルZIPで使う

`Nestrill-v0.2.1-Portable.zip` を空フォルダに展開し、`Start-Nestrill.cmd` で起動できます。最初に `Create-Nestrill-Shortcuts.cmd` を実行すれば、デスクトップ／スタートメニューから起動・終了できます（この版はWindowsのアプリ一覧にインストール登録されません）。終了は `Stop-Nestrill.cmd` です。

ポータブル版では、RSS登録などのデータは**展開先の `data/` などに保存**されます。移動・削除する前に保存データ、ショートカット、自動起動設定をご確認ください。詳しくは [Windows導入手順](SETUP_WINDOWS.md) をご覧ください。

## 主な機能

- RSS購読・カテゴリ管理・更新・既読・お気に入り・OPML入出力
- YouTube公開Atomフィードによる登録チャンネルの新着表示（Googleログイン不要）
- AIセレクト：関心リストと評価履歴などを利用した記事探索
- 複数プロファイル、表示ルール、外観プリセット、背景画像・動画、フォントと文字装飾
- 同一Wi-Fiのスマートフォンからの閲覧、任意の外出先接続

**AIセレクトは任意です。** 利用する場合は別途Ollamaと対応モデルが必要です。標準の選択モデルは `gemma4:e4b-it-qat` ですが、モデル自体は同梱されず、自動ダウンロードも実行もしません。AIセレクトを使わなければOllamaは不要です。

**AIセレクトの初回利用：**「設定 → AIセレクト」で使用モデルを確認してください。モデルを変更した場合は **「AIモデル設定を保存」** を押します。未設定の場合は標準モデル `gemma4:e4b-it-qat` を使用します（Ollamaとモデルの別途導入が必要です）。

## スマートフォン連携とTailscale

スマートフォンでの接続手順と停止・解除方法は [スマホ接続ガイド](MOBILE_SETUP.md) にまとめています。**TailscaleはNestrillとは無関係の第三者サービス**です。外出先で使う場合、利用者自身の判断と責任で導入・アカウント・接続権限・セキュリティ設定を管理してください。Nestrillの利用にTailscaleは必須ではありません。

## ご利用上の注意

- NestrillはPC内のポート **8767** を使用します。別のNestrillやアプリが同じポートを使っていると、同時起動できません。
- RSS・YouTubeやニュースサイトへのアクセス、AIセレクトの外部候補探索にはネットワーク通信が発生します。
- Windowsサインイン時の自動起動のON/OFFは実機確認済みですが、**再サインイン後の自動起動完了までは未検証**です。
- セットアップEXEは**デジタル署名なし**です。配布物のSHA-256を公式リリース掲載の一覧と照合してください。
- アンインストーラーはブラウザ側のサイトデータ（画面表示設定など）を削除しません。必要に応じてブラウザのサイトデータ設定から個別に削除できます。
- Windowsの全環境、すべてのPC・ネットワーク構成での動作を保証するものではありません。
