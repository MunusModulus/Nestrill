# Nestrill v0.2.0 — Windows導入ガイド

## 動作環境

- Windows 11 x64（主な実機検証環境）
- Node.js **22.16以上**： https://nodejs.org/en/download/
- Webブラウザ、RSSを利用するためのネットワーク接続

Node.jsは別途導入が必要です。追加のnpmパッケージは通常不要です。OllamaとAIモデルはAIセレクトを使う場合のみ必要で、Nestrillには同梱されていません。

## 通常のインストール

1. `Nestrill-Setup-v0.2.0.zip` をダウンロードして展開します。
2. 中の `Nestrill-Setup-v0.2.0.exe` を実行します。デジタル署名のないEXEのため、Windowsの警告が出る場合があります。**信頼できる公開元とSHA-256を確認してから**実行してください。
3. インストール先を確認します。既定値は `%LOCALAPPDATA%\Programs\Nestrill` です。必要に応じてデスクトップショートカットの作成を選択します。
4. 「インストール」を押し、完了後に「スタート → すべてのアプリ → N → Nestrill」で起動してください。
5. 通常の終了は「Nestrill を終了」です。

インストール完了画面に、PCから開くアドレス `http://127.0.0.1:8767/` と「スマホ接続ガイドを開く」機能があります。このURLは**Nestrillを動かしているPC自身で使うもの**で、別端末用ではありません。

### 自動起動（任意）

「設定 → 一般」で「Windowsサインイン時にNestrillを自動起動する」をONにすると、Windowsへのサインイン時にサーバーを自動起動する設定を登録します。初期状態はOFFです。自動起動時にはブラウザを開きません。

※設定画面のON/OFF切替は実機確認済みですが、Windows再サインイン後に実際に起動するかは未検証です。

### アンインストール

Windowsの「設定 → アプリ → インストールされているアプリ → Nestrill」から実行します。必要なら起動中の対象サーバーを自動で正常終了させた後、確認を経てインストール先のファイルと**RSS・YouTube登録、設定、閲覧履歴、ログなどを削除**します。別のNestrillインストールや、ほかのNode.jsプロセスは削除・強制終了しません。

**アンインストール後にデータを復元できない場合があるため、必要な情報は事前にバックアップしてください。** ブラウザのサイトデータは別途残ることがあります。

### 以前のリリース候補版からの更新

旧セットアップ版が同じインストール先にある場合、**先にアンインストールしないで**本版のセットアップで同じ場所を選んで更新してください。変更済み・管理外の配布ファイルが見つかった場合は安全のため更新を中断します。古いフォルダを手動削除しないでください。

## ポータブル版

1. `Nestrill-v0.2.0-Portable.zip` を空フォルダに展開します。
2. `Start-Nestrill.cmd` で起動し、`Stop-Nestrill.cmd` で終了します。ショートカット作成を希望する場合は `Create-Nestrill-Shortcuts.cmd` を最初に1回実行してください。
3. 起動中はブラウザで `http://127.0.0.1:8767/` を開けます。

ポータブル版では展開先に `data/`, `run/`, `logs/` が作成されます。削除時は必要な情報をバックアップし、ショートカットや自動起動設定を解除してからフォルダを整理してください。

## スマートフォンから閲覧

[スマホ接続ガイド](MOBILE_SETUP.md) をお読みください。自宅LANと、任意のTailscale利用による外出先接続では操作が異なります。TailscaleはNestrillとは独立した第三者サービスで、導入や設定は利用者自身の責任です。外出先接続を必要としない場合は導入不要です。

## ヘルプ

- 起動できない：Node.js 22.16以上がインストール済みか、ポート8767が他のアプリに使用されていないかを確認してください。
- AIセレクトでモデルが利用できない：Ollamaの起動状態と、そのモデルがPCに存在するかを確認してください。
- 接続できない／スマホ通信がおかしい：[MOBILE_SETUP.md](MOBILE_SETUP.md) の接続停止手順と応急処置をご覧ください。
