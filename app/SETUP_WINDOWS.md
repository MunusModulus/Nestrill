# Nestrill Standard v0.2.4 — Windows 導入・更新ガイド

## 初回導入

1. Windows 11 x64 で Node.js 22.16以上を導入します。
2. `Nestrill-Setup-v0.2.4.exe` を起動し、通常は表示される既定のインストール先を使用します。管理者権限は不要です。
3. スタートメニューの **すべてのアプリ → N** にある「Nestrill」から起動します。「Nestrill を終了」から終了できます。
4. PCのブラウザで `http://127.0.0.1:8767/` を開きます。

## 旧版からの更新

- **アンインストールせず**、インストール済みと同じ場所へ上書きします。
- 更新前に `data/` を含めインストール全体のバックアップを保存してください。動作中の場合は、所有者を確認した停止処理が行われます。
- 旧版の管理対象ファイルに未知の改変がある場合は、安全のため更新を中止します。拒否された際に強制上書きや手動削除をしないでください。
- 更新後はスタートメニューから起動し、RSS・AI評価履歴・設定が維持されていることを確認してください。
- v0.2.4 RC03で上書き更新・データ保持・主要機能を実機確認済みです。正式版の新規導入は実機未検証です。

## ポータブル版

- `Nestrill-v0.2.4-Portable.zip` を新しい専用フォルダへ展開し、`Start-Nestrill.cmd` で起動します。
- Standardのインストール済み環境と同時起動しないでください。既定では同一ポート8767を利用します。
- アンインストーラーはインストーラー版専用です。ポータブル版はデータの保全を確認してから作業してください。

スマホ閲覧・Tailscale接続については、スタート → すべてのアプリ → N →「Nestrill スマホ接続ガイド」、または `MOBILE_SETUP.md` を参照してください。
