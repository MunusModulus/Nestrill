# Nestrill — スマートフォン接続ガイド

このガイドは、Nestrillをスマートフォンでも閲覧したい方のための説明です。**PCだけで使う場合、この設定は不要です。**

Nestrillを動かすPCの電源が入っていて、Nestrillが起動している必要があります。接続URLと8桁の接続コードは第三者に教えないでください。

## 1. 自宅など、同じWi-Fiで使う

1. PCでスタートメニューの「Nestrill」を起動します。
2. Nestrillのインストール先フォルダを開き、**`Start-Nestrill-Mobile.cmd`** を実行します。
   - 標準のインストール先：`%LOCALAPPDATA%\Programs\Nestrill`
   - PCにネットワークが複数ある場合は、スマートフォンと同じWi-Fi/LANのIPアドレスを選びます。
3. メモ帳に表示される**スマホ用URL**と**8桁の接続コード**を確認します。URLはPCのWi-Fi環境によって変わるため、このガイドの固定URLを入力するのではなく、表示されたURLを使ってください。
4. スマートフォンを**PCと同じWi-Fi**に接続し、スマホのブラウザでそのURLを開きます。接続コードを求められたら、PCに表示された8桁のコードを入力します。
5. Windowsファイアウォールから許可を尋ねられた場合は、**信頼できるプライベートネットワークに限定**してください。パブリックネットワークでは許可しないでください。

**注意：家庭内LAN接続はHTTP通信です。** 公共Wi-Fi、職場など管理者の許可がないネットワーク、信頼できない共有ネットワークでは使用しないでください。ルーターのポート開放は行わないでください。

スマホ閲覧を停止するには、**`Stop-Nestrill-Mobile.cmd`** を実行します。PC版のNestrillは引き続き使えます。

## 2. 外出先から使う（任意・Tailscaleを利用する場合）

外出先からの接続は**必須機能ではありません**。以下の「Tailscale利用について」を了承し、必要だと判断した方だけ設定してください。

**Tailscaleは、Nestrillおよび開発者 Munus Modulus とは独立した、第三者のサービスです。** Nestrillの開発者はTailscaleの運営元ではなく、提携・後援・代理・公式サポートを行う関係にもありません。

Tailscaleの導入・アカウント作成・端末登録・アクセス権限・利用規約・費用・通信環境・セキュリティ設定は、**利用者自身の判断と責任**で管理してください。サービス仕様の変更、障害、利用者の設定ミスなどによるTailscale側の問題について、Nestrillからその動作や継続利用を保証することはできません。

**これらを了承できる場合に限り、Tailscaleを使った外出先接続を有効にしてください。** Tailscale自体の契約やサービスに関する質問は、Tailscaleの公式情報・サポートをご利用ください。なお、この説明はNestrill自身の不具合や、法令上免除できない責任まで免責する趣旨ではありません。

### 外出先接続の手順

1. Tailscaleを**PCとスマートフォンの両方**に、公式サイトから利用者自身で導入します。両端末を同じtailnet（通常は同じアカウント）に接続し、利用者自身でアクセス権限を確認します。
2. 自宅PCでNestrillを起動し、まず上記の **`Start-Nestrill-Mobile.cmd`** でスマホ閲覧を有効にします。
3. 同じインストール先の **`Start-Nestrill-Remote.cmd`** を実行します。NestrillはTailscale Serveを使い、tailnet内だけで利用するHTTPSの中継を設定します。
4. メモ帳に表示される `https://...ts.net/mobile/` のURLを確認します。
5. スマートフォン側でTailscaleを接続し、そのURLを開きます。必要に応じて上記の8桁の接続コードを入力します。

**Tailscale Funnel（インターネット一般公開）やルーターのポート開放は使用しません。** 既存のTailscale Serve設定がある場合、Nestrillは上書きしないよう開始を中断します。接続がうまくいかない場合でも、安易に公開設定を変更しないでください。

外出先接続を停止するときは、**`Stop-Nestrill-Remote.cmd`** を先に実行します。その後、必要なら `Stop-Nestrill-Mobile.cmd` でLAN側の接続も停止します。外出先接続を有効にしたまま先にLAN接続を止めないでください。

## 3. 接続の解除・トラブル時

### スマホのモバイル通信が使えなくなったとき（応急処置）

Tailscaleを利用しているスマートフォンで、モバイル回線の通信ができなくなったり、他のアプリもインターネットにつながらなくなったりした場合は、次の操作で改善することがあります。

1. **スマートフォンのTailscaleをOFF（切断）**にします。
2. **スマートフォンのモバイルデータ通信をOFF**にします。
3. **モバイルデータ通信をON**に戻します。

これは利用者の実例で通信が回復したことのある**応急処置**であり、原因の特定や復旧を保証するものではありません。再度Tailscaleを有効にする前に、モバイル通信が通常どおり利用できるか確認してください。改善しない場合は端末のネットワーク設定や通信事業者・Tailscaleの案内をご確認ください。


- 接続できない場合は、まずPCでNestrillが起動していること、スマホのWi-FiまたはTailscaleの接続状態を確認してください。
- 外出先から接続できなくなった場合は、Tailscale側の接続と設定を確認し、**`Status-Nestrill-Remote.cmd`** でNestrill側の接続状況を調べられます。
- 以前ログインした端末の認証をすべて無効化したい場合は **`Revoke-Nestrill-Mobile-Logins.cmd`** を実行し、案内に従ってください。記事やRSS登録は削除しません。
- 接続コード・URL・ログイン情報を画像やSNSで公開しないでください。共有PCや公共ネットワークではモバイル接続を有効にしないでください。

Nestrillをアンインストールすると、インストール先の接続設定と利用データも削除されます。ただし、**第三者のTailscaleアプリ、アカウント、端末登録そのものは削除されません**。Tailscaleを使わなくなる場合は利用者自身で管理してください。

## PCでのアクセスについて

PC自身からNestrillを開くURLは **`http://127.0.0.1:8767/`** です。これをPCのブラウザのお気に入りに登録すると便利です。**このアドレスはスマートフォンからPCに接続するためのアドレスではありません。** また、Nestrillが起動していなければ開けません。
