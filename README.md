# Nestrill

Nestrill（ネストリル）は、RSSとYouTubeの新着をまとめて閲覧できる、Windows向けのローカルリーダーです。ブラウザで利用でき、表示や背景を好みに合わせてカスタマイズできます。必要に応じて、ローカルAIによる記事探索「AIセレクト」も利用できます。

**最新版：v0.2.3（Standard版）**

Windows 11 x64でRC08からの上書き更新・起動・既存データ保持・主要機能の動作を実機確認済みです。正式版の新規インストールは実機未検証です。

## 主な機能

- **RSSリーダー**：フィード登録、カテゴリ分け、記事の更新・既読管理・お気に入り、OPMLのインポート／エクスポート
- **YouTube新着チェック**：登録チャンネルの公開Atomフィードを利用。Googleアカウントでのログインは不要
- **AIセレクト（任意）**：関心リストや評価履歴などをもとに、ローカルのOllamaで読みたい記事を探索。ジャンル指定やランダム探索にも対応
- **記事表示ルール**：RSSとAIセレクトで共通の非表示設定。タイトルの1語指定、および `"A"+"B"`（AND）・`"A"or"B"`（OR）に対応
- **表示カスタマイズ**：フォント、色、文字装飾、背景画像・動画、外観プリセット、ジャンルアイコン、複数プロファイル
- **スマートフォン閲覧（追加設定が必要）**：同じWi-Fi内での閲覧や、任意のTailscale利用による外出先からのアクセス

記事の非表示ルールは**画面での表示だけ**を制御します。AIの記事探索・関連性評価・評価履歴・記事データは削除・変更しません。ドメインとURLパスの条件も利用できますが、Googleニュース経由などで元記事のパスを取得できない場合、そのパス条件では一致判定できません。

## 動作環境

- **Windows 11 x64**（主な動作確認環境）
- **Node.js 22.16以上**（別途インストールが必要）
- Webブラウザと、RSS等を取得するためのインターネット接続

Node.js：[公式ダウンロードページ](https://nodejs.org/en/download/)

**AIセレクトを利用しない場合、Ollamaは不要です。** 利用する場合はOllamaと対応モデルを別途準備してください。初期選択モデルは `gemma4:e4b-it-qat` ですが、モデルの同梱・自動ダウンロードは行いません。既存のモデル設定は上書きされません。

## インストールと起動

1. [Releases](https://github.com/MunusModulus/Nestrill/releases/tag/v0.2.3) から **`Nestrill-Setup-v0.2.3.zip`** を取得します。
2. ZIPを展開し、中の **`Nestrill-Setup-v0.2.3.exe`** を実行します。
3. インストール後、Windowsの **スタート → すべてのアプリ → N → Nestrill** から起動します。ブラウザが自動で開きます。
4. 終了するときは、同じN欄の **「Nestrill を終了」** を選びます。

Nestrillが起動中なら、PCのブラウザで **`http://127.0.0.1:8767/`** を直接開くこともできます。ブラウザを閉じるだけではNestrillのサーバーは終了しません。

Windowsサインイン時の自動起動は、**設定 → 一般** からON/OFFできます（初期OFF）。

インストール不要の **`Nestrill-v0.2.3-Portable.zip`** も公開しています。専用フォルダに展開後、`Start-Nestrill.cmd` で起動できます。インストール版とポータブル版は同時に起動しないでください。

**旧版から更新するときは先にアンインストールしないでください。** 事前に利用データをバックアップし、Nestrillを終了して、同じインストール先を選んで上書き更新します。保護機能が想定外のファイル変更を検出すると更新を中断します。その場合、古いファイルやデータを強制削除しないでください。

詳しい手順：[Windows導入ガイド](app/SETUP_WINDOWS.md) ／ [ポータブル版の説明](app/README.md)

## Nestrill X Extension（X／旧Twitter連携）

Nestrill X Extensionは、Heliumブラウザ向けのオプション拡張機能です。

- NestrillとX（旧Twitter）で共通の左サイドバーを使用
- 左サイドバーを維持したまま、右側の画面をRSS・YouTube・AIセレクト・Xに切り替え
- Xのページを背面に保持し、通常の切り替え時に閲覧位置を維持しやすくする
- NestrillとXの背景・外観を統一
- 使用していない背面のXを手動で終了可能

RSS登録、AIセレクト、設定などはNestrill本体と共通です。専用のNestrill本体を別途インストールする必要はありません。

Nestrill X Extensionは任意の追加機能であり、通常版のインストーラーには含まれません。

**[Nestrill X Extension v1.0.0の配布ページ](https://github.com/MunusModulus/Nestrill/releases/tag/x-extension-v1.0.0)** からZIPを取得し、Heliumにパッケージ化されていない拡張機能として読み込みます。

詳しい導入・更新・削除手順と権限については [導入ガイド](x-extension/README_FIRST.md) をご覧ください。Nestrill v0.2.3とHeliumの組み合わせで実機確認済みです。

## スマートフォンで利用する（任意）

Nestrillは、PCで動作させたままスマートフォンからも閲覧できます。PCのみで利用する場合は、この設定は不要です。

### 自宅Wi-Fiで利用する

1. PCでNestrillを起動します。
2. Nestrillのインストール先にある `Start-Nestrill-Mobile.cmd` を実行します。
3. スマートフォンをPCと同じWi-Fiに接続します。
4. PCに表示されたスマホ用URLを開き、8桁の接続コードを入力します。

標準のインストール先は以下のとおりです。

`%LOCALAPPDATA%\Programs\Nestrill`

Windowsのエクスプローラーのアドレスバーに入力すると開けます。ポータブル版では展開先を開いてください。

スマホ接続を停止するには `Stop-Nestrill-Mobile.cmd` を実行します。

家庭内LANでの接続はHTTP通信です。信頼できない共有ネットワークや公共Wi-Fiでは使用しないでください。

### 外出先で利用する（Tailscale）

1. PCとスマートフォンの両方にTailscaleを導入し、同じtailnetに接続します。
2. 上記の手順でスマホ接続を開始します。
3. `Start-Nestrill-Remote.cmd` を実行します。
4. 表示されたHTTPSのURLをスマートフォンで開きます。必要に応じて接続コードを入力します。

外出先接続を停止するには `Stop-Nestrill-Remote.cmd` を実行します。

TailscaleはNestrillおよび開発者とは独立した第三者サービスです。導入・アカウント管理・接続権限・セキュリティ設定は、利用者自身の判断と責任で行ってください。Tailscaleは必須ではありません。

スマホからの利用中はPCとNestrillを起動しておく必要があります。ルーターのポート開放やTailscale Funnelによる一般公開は行わないでください。

**詳細な接続・停止・認証解除手順、セキュリティ上の注意については、[スマートフォン接続ガイド](app/MOBILE_SETUP.md) を必ずご確認ください。**

ガイドはインストール先の `MOBILE_SETUP.md` にも同梱されています。

## データとアンインストールについて

Windowsの「設定 → アプリ → インストールされているアプリ」からアンインストールできます。

**インストール版をアンインストールすると、そのインストール先に保存されたRSS・YouTube登録、設定、閲覧履歴などの利用データも削除されます。** 必要なデータがある場合は、事前にバックアップしてください。

ポータブル版の利用データは、展開先フォルダ内に保存されます。

## ご利用上の注意

- セットアップEXEには**コード署名がありません**。ダウンロード元を確認し、必要に応じてリリース添付の `SHA256SUMS.txt` と照合してください。
- RSS・YouTube・外部記事の取得やAIセレクトの候補探索ではインターネット通信が発生します。AIセレクトのモデル推論は利用者のローカルOllamaで行います。
- Nestrill X Extensionは別配布の追加拡張機能です。通常版には含まれていません。
- 全Windows環境・全機能・全ネットワーク構成での動作を保証するものではありません。
